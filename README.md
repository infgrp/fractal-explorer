# 프랙탈 탐험 — 만델벌브·멘거 스펀지 레이마칭

폴리곤 메시 없이, three.js `ShaderMaterial` 의 프래그먼트 셰이더에서 **레이마칭 + 거리 추정 함수(SDF)** 로 3D 프랙탈을 그리고, 그 속을 카메라로 날아다니며 빛을 비춰 보는 실험입니다.

라이브: https://infgrp.github.io/fractal-explorer/

`index.html` 한 파일로 동작합니다. 백엔드는 없고, three.js 0.170 을 CDN에서 불러오므로 인터넷 연결이 필요합니다. WebGL2 가 되는 브라우저(최신 Chrome·Edge·Safari)에서 여세요.

## 그리는 방법
- 화면 전체를 덮는 사각형 하나에 셰이더를 걸고, 픽셀마다 광선을 쏩니다.
- 광선은 그 점에서 프랙탈까지의 거리 추정값(SDF)만큼씩 앞으로 갑니다. 이 거리보다 가까운 곳에는 표면이 없으므로 안전하게 건너뛸 수 있습니다.
- **표면에 닿았다고 보는 기준을 "그 거리에서 한 픽셀이 차지하는 크기"로 둡니다.** 그래서 가까이 다가갈수록 더 작은 구조까지 계산하고, 확대해도 디테일이 깨지지 않습니다.
- 그림자(부드러운 그림자), 틈새 그늘(AO), 테두리 빛, 걸음 수에 따른 빛 무리, 안개를 모두 같은 거리 함수로 계산합니다. 안개·손전등 거리도 표면까지 거리에 맞춰 바뀌므로 어느 배율에서나 같은 느낌으로 보입니다.

| 프랙탈 | 거리 추정 |
|---|---|
| 만델벌브 | 구면 좌표 거듭제곱 zⁿ + c (기본 n = 8), DE = ½·log r · r / dr |
| 멘거 스펀지 | 상자에서 3배씩 작아지는 십자 구멍을 차례로 빼는 식 |
| 무한 스펀지 | 바깥 상자 없이 구멍만 반복 — 끝없는 통로 속 |

## 비행
- 비행 속도를 **카메라에서 표면까지 거리에 비례**하게 둡니다(CPU 에서도 같은 SDF 를 배정밀도로 계산). 가까이 갈수록 저절로 느려져 표면에 부딪히지 않고 계속 파고들 수 있습니다.
- **자동 확대(Z)**: 보는 방향으로 계속 다가갑니다. 남은 거리가 일정 비율로 줄어들어 배율이 끝없이 커집니다.
- 한계: 셰이더는 GPU 단정밀도(float32)로 계산하므로 표면까지 거리가 약 10⁻⁶ 아래(배율 약 10⁵~10⁶배)로 내려가면 표면이 거칠어집니다. 그 근처에서 경고를 띄우고 자동 확대를 멈춥니다.

## 조명 실험
- **손전등**: 카메라에서 앞으로 비추는 원뿔. 색·세기·폭 조절.
- **해**: 방향(방위·높이)과 색, 부드러운 그림자.
- **빛 놓기(L)**: 지금 위치 조금 앞에 색 있는 점광원을 놓습니다(최대 6개). 물러나서 틈새에 비친 빛을 보세요.

## 화질
움직이는 동안은 해상도 슬라이더 비율(기본 75%)로 그리고, 멈추면 원래 해상도로 다시 그립니다(멈추면 선명하게). 느리면 해상도·최대 걸음을 낮추고, 디테일 값을 키우세요.
